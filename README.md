# 🚗 **AutoData: Explorando Anuncios de Vehículos** 🏎️

## 📋 Descripción
En el mercado de venta de vehículos, la gran cantidad de anuncios en línea dificulta identificar patrones sobre precios, marcas y características que influyen en la venta rápida de un vehículo. Los datos no siempre están limpios o completos, lo que hace que el análisis manual sea ineficiente.

## 🎯 Objetivo
Practicar tareas clave de ingeniería de software aplicadas a datos reales, incluyendo la creación y gestión de entornos virtuales de Python, limpieza y análisis básico de datos, y desarrollo de una pequeña aplicación web que permita explorar anuncios de coches de manera interactiva.

## 📊 Resultados + visualizaciones
Creé gráficos interactivos que me permitieron explorar cómo se distribuyen los precios según la marca, el modelo y el año de los vehículos.
Pude identificar patrones en los anuncios que tenían mayor visibilidad o se vendían más rápido.
Además, desarrollé una pequeña aplicación web que me permitió filtrar y explorar los anuncios de manera dinámica, haciendo que los datos fueran mucho más accesibles e intuitivos.

## 👩‍💻 Rol + aprendizajes clave
Me encargué de crear y gestionar entornos virtuales en Python, aplicando buenas prácticas de desarrollo desde el inicio del proyecto.
Trabajé con datos reales, limpiándolos y visualizándolos con pandas, numpy y plotly, lo que me ayudó a entender mejor cómo comunicar hallazgos de manera clara.
También desarrollé una aplicación web simple usando Flask, integrando mis conocimientos de front-end para que los datos fueran interactivos.
Por último, reforcé mi flujo de trabajo colaborativo usando Git y GitHub, asegurándome de mantener un control de versiones organizado y eficiente.
